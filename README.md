# Ruka Browser

**Ruka Browser** is a private, local-first desktop browser for Windows and Linux with a built-in local AI agent, chat, music and studio tools.

- Website: https://ruka.xochat.online
- Downloads: https://ruka.xochat.online/#downloads
- Release archive: https://ruka.xochat.online/#archive
- Updates: https://updates.xochat.online

This repository publishes the public Ruka Browser release assets and update manifests.

Ruka Browser does not require a cloud account and does not include telemetry. Local files, history, chats and settings stay on the device.
